## Описание
В работе проведен рефакторинг кода для приведения его в соответствие с пятью принципами SOLID:
1. **SRP** — разделение ответственности (OrderProcessor и NotificationService).
2. **OCP** — открытость для расширения (интерфейс Shape).
3. **LSP** — подстановка подтипов (выделение EngineVehicle).
4. **ISP** — разделение интерфейсов (Printer, Scanner, Fax).
5. **DIP** — инверсия зависимостей (интерфейс Storage).

## Команды для сборки и запуска
1. Сборка проекта:
   `mvn clean package`
2. Запуск приложения:
   `java -jar target/java-lab8-1.0-SNAPSHOT.jar`
